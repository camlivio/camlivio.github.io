# camlivio.github.io

Personal website of Camila Lívio, built with [Quarto](https://quarto.org) and served by GitHub Pages from `docs/`.

## Updating the site

1. Edit the `.qmd` pages (`index.qmd`, `aboutme.qmd`, `teaching.qmd`, `publications.qmd`) or the styles in `theme.scss`.
2. Run `quarto render` in this folder. It rebuilds `docs/`.
3. Commit everything, including `docs/`, and push. The site updates within a minute or two.

The previous Beautiful Jekyll version of the site is preserved on the `jekyll-archive` branch.
